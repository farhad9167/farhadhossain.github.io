# Md. Farhad Hossain — Portfolio

A responsive one-page portfolio website for GitHub Pages.

## Files
- `index.html` — website content
- `style.css` — design and responsive styling
- `script.js` — mobile menu and current year

## Before publishing
Replace these placeholders in `index.html`:
- `YOUR_EMAIL@example.com`
- `https://github.com/`
- `https://www.linkedin.com/`

You can also add your real GitHub project URLs to the project cards.

## GitHub Pages
1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open repository Settings → Pages.
4. Select Deploy from a branch → `main` → `/ (root)`.
5. Your website will be available at `https://YOURUSERNAME.github.io/`.
